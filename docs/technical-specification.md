# ТЗ: Бот-помощник для учёбы

## Задание

Telegram-бот, который помогает ученикам не забывать о дедлайнах, расписании и важных событиях.

## Функционал

- Регистрация пользователя и модель данных через SQLAlchemy (пользователи, события, напоминания).
- Добавление разового события с датой, временем и описанием.
- Поддержка повторяющихся событий (ежедневно/еженедельно).
- Напоминания, которые переживают перезапуск бота (хранятся в БД).
- Постраничный вывод списка ближайших событий, если их много (пагинация).
- Редактирование и удаление события/напоминания.

### Дополнительно (бонус)

- Мотивационные сообщения/цитаты по расписанию.
- Личная статистика по выполненным и просроченным задачам.

## Ключевые качества

- Корректность и надёжность напоминаний после рестарта.
- Обработка часовых поясов.
- Покрытие тестами логики повторов и расчёта времени следующего напоминания.

## Технологии

- Язык: Python.
- Бот: aiogram (async) или python-telegram-bot.
- Данные: SQLite через ORM (SQLAlchemy), обязательно.
- Планировщик: APScheduler (job store).
- Тесты: pytest.

## Общие требования

- Конфигурация (токены, пути, секреты) через переменные окружения (`.env`).
- Логирование ключевых событий и ошибок через модуль `logging`.
- Автоматические тесты (pytest): минимум 5 на бизнес-логику.
- Код структурирован по слоям/модулям: данные, бизнес-логика, интерфейс.
- Валидация входных данных и обработка ошибок (ввод пользователя, ответы внешних сервисов).
- README с описанием проекта, архитектуры и инструкцией по запуску, включая запуск тестов.
